10/**
11 * Moves a single manifest entry into place. Three behaviours, in order:
12 *
13 *   1. Hardlink fast path (deploy only): if a file at the link-dest (current production) matches the
14 *      source by size + mtime, hardlink it instead of copying bytes. This is the per-file analogue of
15 *      `rsync --link-dest`: unchanged files cost no bytes.
16 *   2. Resumable byte copy: otherwise stream the bytes in chunks, stopping cleanly at the deadline and
17 *      returning PARTIAL with the offset reached, so a file larger than one budget resumes mid-file
18 *      next call. The destination is truncated to the checkpointed offset before appending, so a dead
19 *      request can never corrupt the file.
20 *   3. Verify: on completion the destination's size must equal the manifest size, and its mtime is set
21 *      to the source mtime so a later deploy's delta still recognises it as unchanged.
22 *
23 * Pure PHP (no WordPress); unit-testable against temp dirs.
